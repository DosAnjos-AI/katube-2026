# arquivos/temp/

Intermediate working directory for the pipeline. Holds the chain of
subfolders generated by the modules during processing.

## Structure

    arquivos/temp/{id}/<subfolders numbered by stage>

Example subfolders: 01-arquivos_originais, 06-stt_whisper, 07-stt_wav2vec.

## Lifecycle

Transient content, removed by M15 (cleanup) at the end of each audio
file, according to the `MASTER['cleanup']` field in `config.py`.

The content of this directory is not versioned (see .gitignore).
This README exists to preserve the folder in the repository.
